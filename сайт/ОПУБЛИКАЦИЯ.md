# Как опубликовать игру и сайт — пошаговая инструкция

> ✅ Сайт уже опубликован: **https://glubin-projects.netlify.app**

## 1. Сайт с играми

### Вариант А: GitHub Pages (бесплатно, навсегда)
1. Создай аккаунт на https://github.com
2. Создай репозиторий, например `power-mishriks-games`
3. Загрузи всё содержимое папки `сайт/` в репозиторий
4. Зайди в **Settings → Pages**, выбери `main` / `root`, сохрани
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://твой-логин.github.io/power-mishriks-games/`

### Вариант Б: Netlify (ещё проще)
1. Зайди на https://app.netlify.com
2. Перетащи папку `сайт/` мышью в окно браузера
3. Получишь ссылку вида `https://_random_.netlify.app`
4. В настройках можно поменять на красивый домен

### Вариант В: Hosting на Яндексе / Timeweb
Если есть свой домен — загрузи файлы по FTP.

## 2. Что загрузить на сайт

```
сайт/
├── index.html              ← главная страница (всё готово)
├── игры/
│   ├── глубина/
│   │   ├── index.html      ← сама игра
│   │   └── PressStart2P-Regular.ttf
│   └── voxel-mine.zip      ← твоя игра Voxel Mine
└── видео/
    ├── СЦЕНАРИИ.md         ← сценарии для TikTok и YouTube
    ├── сделать_обложки.py  ← генератор обложек
    ├── preview-youtube.png
    ├── preview-tiktok.png
    └── cover-glubina.png
```

> Важно: `/recipes` и `видео/` можно не загружать на хостинг — они для тебя.

## 3. Видео для TikTok

### Как снять
1. Открой игру в браузере на компьютере
2. Включи запись экрана:
   - Windows: `Win + G` → Запись
   - macOS: `Cmd + Shift + 5`
   - Или установи OBS Studio (бесплатно)
3. Играй 2–3 минуты, потом обрежь до самого интересного
4. Смонтируй в CapCut (бесплатно) — добавь субтитры и музыку
5. Следуй таймкоду из `видео/СЦЕНАРИИ.md`

### Описание (готовое)
```
Я сделал игру, в которую не могу перестать играть 🎮
Глубина 4.0 — аркадная буровая: бури, собирай руду, уворачивайся от червей 🔥
Играть бесплатно — ссылка в профиле 👆
#игра #индиигра #геймдев #браузернаяигра #разработкаигр #глубина
```

## 4. Видео для YouTube

### Как снять
1. OBS Studio → запись области экрана с игрой
2. Запиши 10–15 минут геймплея с комментарием
3. Обрежь лишнее в любом видеоредакторе
4. Добавь миниатюру `preview-youtube.png`
5. Вставь описание и таймкоды из `видео/СЦЕНАРИИ.md`

### Название (варианты)
- «Я сделал игру за N дней — Глубина 4.0»
- «Аркадная буровая на чистом JavaScript | Глубина 4.0»
- «Моя первая игра, в которую реально играет моя семья»

## 5. Первые подписчики

| Канал | Что делать |
|-------|-----------|
| **TikTok** | 1 ролик в день, первые 2 секунды — самый яркий момент |
| **YouTube Shorts** | загрузи те же ролики, что и в TikTok |
| **Telegram** | создай канал игры, публикуй обновления |
| **Reddit** | r/IndieDev, r/gamedev — покажи скриншоты и расскажи историю |
| **Друзья** | просто скинь ссылку — первые 100 игроков придут отсюда |

## 6. Дальнейшее развитие (чтобы стало популярным)

Из действительно важного:
1. **Кнопка «Поделиться результатом»** — игрок копирует «Я достиг 1270 м, побей меня!»
2. **Ежедневные задания** — возвращение каждый день
3. **Глобальная таблица лидеров** — соревнование
4. **APK через Capacitor** — игра на телефоне
5. **Перевод на английский** — аудитория ×10
